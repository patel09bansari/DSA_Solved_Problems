<h2><a href="https://www.geeksforgeeks.org/problems/triplets-with-sum-with-given-range/1">Triplets with Sum in Range</a></h2><h3>Difficulty Level: Medium</h3><hr><p><span style="font-size: 18px;">Given an array <strong>arr[] </strong>&nbsp;and a range from <strong>l</strong> to <strong>r</strong>, the task is to count the number of triplets having a sum in the range [l, r].</span></p>
<p><span style="font-size: 18px;"><strong>Examples :</strong></span></p>
<pre><span style="font-size: 18px;"><strong>Input: </strong>arr = [8, 3, 5, 2], l = 7, r = 11
<strong>Output:</strong> 1
<strong>Explanation:</strong> There is only one triplet [2, 3, 5] having sum 10 in range [7, 11].</span></pre>
<pre><span style="font-size: 18px;"><strong>Input: </strong>arr = [5, 1, 4, 3, 2], l = 2, r = 7
<strong>Output:</strong> 2
<strong>Explanation:</strong> There are two triplets having sum in range, [1,4,2] and [1,3,2].<br></span></pre>
<p><span style="font-size: 18px;"><strong>Constraints:</strong><br>1 ≤ arr.size≤ 10<sup>3</sup><br>1 ≤ arr[i] ≤ 10<sup>3</sup><br>1 ≤ l ≤ r ≤ 10<sup>9</sup></span></p>
